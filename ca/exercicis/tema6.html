Exercicis — Tema 6: Programació Orientada a Objectes

Per a la realització dels exercicis heu d’emprar el projecte t06-poo que està disponible al repositori del curs: https://github.com/UIB-23200-Programacion/t06-poo. Navegueu al lloc i seguiu les instruccions de README.md per copiar el repositori en el vostre entorn local de GitHub i obrir un Codespace per treballar en els exercicis.

En tots els exercicis d’aquest tema es programen classes. Les regles dels temes anteriors s’apliquen ara a cada mètode:

  • cada mètode ha de tenir anotacions de tipus i docstring;
  • si no es compleix una precondició, el mètode ha de llançar ValueError amb un missatge descriptiu (vegeu secció 3.4 del tema 3);
  • si un operador rep un operand d’un tipus que no sap tractar, el mètode màgic ha de retornar NotImplemented (vegeu secció 6.4 del tema 6).

Exercici 6.9: Classe Matriz (mòdul matriz.py)

Una Matriz de \(n\) files i \(m\) columnes es desa com una llista de files: [[a11, a12], [a21, a22]]. Els elements són nombres (int o float).

Nota6.9.1 Constructor __init__(self, filas):

Crea la matriu a partir d’una llista de files. Precondicions: la llista no és buida, les files no són buides i totes tenen la mateixa longitud. El constructor ha de copiar les files, perquè modificar després la llista original no modifiqui la matriu.

ConsellExemple 
A = Matriz([[1, 2], [3, 4]])
Matriz([[1, 2], [3]])     # ValueError: filas de distinta longitud
Matriz([])                # ValueError: matriz vacía
Nota6.9.2 Mètodes de classe identidad(n) i ceros(n, m):

Constructors alternatius (@classmethod): identidad(n) retorna la matriu identitat \(I_n\) i ceros(n, m) la matriu nul·la de \(n \times m\). Precondició: \(n, m \geq 1\).

ConsellExemple 
print(repr(Matriz.identidad(2)))   # Matriz([[1, 0], [0, 1]])
print(repr(Matriz.ceros(2, 3)))    # Matriz([[0, 0, 0], [0, 0, 0]])
Nota6.9.3 Propietat dimensiones i accés A[i, j]:

La propietat dimensiones retorna la tupla (n, m). El mètode __getitem__ permet llegir un element amb la notació A[i, j] (fila i, columna j, comptant des de 0): Python passa la tupla (i, j) com a argument.

ConsellExemple 
A = Matriz([[1, 2], [3, 4]])
print(A.dimensiones)                          # (2, 2)
print(Matriz([[1, 2, 3], [4, 5, 6]]).dimensiones)   # (2, 3)
print(A[1, 0])                                # 3
Nota6.9.4 Representació __repr__ i __str__:

repr(A) retorna Matriz([[1, 2], [3, 4]]). str(A) (i per tant print(A)) retorna una fila per línia, amb els elements separats per un espai.

ConsellExemple 
A = Matriz([[1, 2], [3, 4]])
print(repr(A))   # Matriz([[1, 2], [3, 4]])
print(A)
# 1 2
# 3 4
Nota6.9.5 Igualtat __eq__:

Dues matrius són iguals si tenen les mateixes dimensions i els mateixos elements. Si l’altre operand no és una Matriz, retorna NotImplemented.

ConsellExemple 
print(Matriz([[1, 2], [3, 4]]) == Matriz([[1, 2], [3, 4]]))   # True
print(Matriz([[1, 2]]) == Matriz([[1], [2]]))                 # False
Nota6.9.6 Suma i resta __add__, __sub__:

Suma i resta element a element. Precondició: les dues matrius tenen les mateixes dimensions.

ConsellExemple 
A = Matriz([[1, 2], [3, 4]])
B = Matriz([[0, 1], [1, 0]])
print(repr(A + B))                    # Matriz([[1, 3], [4, 4]])
print(A - A == Matriz.ceros(2, 2))    # True
Nota6.9.7 Producte per un escalar __mul__, __rmul__:

A * k i k * A, amb k un int o un float, multipliquen cada element per k. Per a qualsevol altre tipus, retornen NotImplemented.

ConsellExemple 
A = Matriz([[1, 2], [3, 4]])
print(repr(2 * A))     # Matriz([[2, 4], [6, 8]])
print(repr(A * 0.5))   # Matriz([[0.5, 1.0], [1.5, 2.0]])
Nota6.9.8 Producte de matrius __matmul__ (operador @):

Python reserva l’operador @ per al producte de matrius: A @ B crida A.__matmul__(B). Si \(A\) és \(n \times m\) i \(B\) és \(m \times p\), el producte és la matriu \(n \times p\) amb \[ (AB)_{ij} = \sum_{k=1}^{m} a_{ik}\, b_{kj}. \] Precondició: el nombre de columnes de \(A\) coincideix amb el nombre de files de \(B\).

ConsellExemple 
A = Matriz([[1, 2], [3, 4]])
B = Matriz([[0, 1], [1, 0]])
print(repr(A @ B))   # Matriz([[2, 1], [4, 3]])
print(repr(B @ A))   # Matriz([[3, 4], [1, 2]])  — el producto no es conmutativo
Nota6.9.9 Mètode traspuesta():

Retorna la matriu transposada \(A^T\), amb \((A^T)_{ij} = a_{ji}\).

ConsellExemple 
print(repr(Matriz([[1, 2], [3, 4]]).traspuesta()))   # Matriz([[1, 3], [2, 4]])
print(Matriz([[1, 2, 3], [4, 5, 6]]).traspuesta().dimensiones)   # (3, 2)
Nota6.9.10 Mètode determinante():

Calcula el determinant per desenvolupament de Laplace al llarg de la primera fila: \[ \det(A) = \sum_{j=1}^{n} (-1)^{1+j}\, a_{1j}\, \det(A_{1j}), \] on \(A_{1j}\) és la submatriu que resulta d’eliminar la fila 1 i la columna \(j\). És una definició recursiva (tema 3): el cas base és una matriu \(1 \times 1\), el determinant de la qual és el seu únic element. Precondició: la matriu és quadrada.

ConsellExemple 
print(Matriz([[1, 2], [3, 4]]).determinante())                    # -2
print(Matriz([[2, 0, 1], [1, 3, 2], [1, 1, 2]]).determinante())   # 6
print(Matriz.identidad(3).determinante())                         # 1
ImportantCost del desenvolupament de Laplace

El desenvolupament de Laplace fa \(n\) crides recursives amb matrius d’ordre \(n - 1\), així que el seu cost creix com \(n!\). És adequat per a matrius petites; per a matrius grans es fa servir l’eliminació gaussiana, que costa de l’ordre de \(n^3\) operacions.

Nota6.9.11 Potència __pow__ i els nombres de Fibonacci:

A ** k retorna la potència \(A^k\), amb \(A^0 = I\). Precondicions: la matriu és quadrada i \(k\) és un enter no negatiu.

ConsellExemple 
F = Matriz([[1, 1], [1, 0]])
print(F ** 10)
# 89 55
# 55 34
print(F ** 0 == Matriz.identidad(2))   # True
ImportantFibonacci amb matrius

Per inducció es demostra que \[ \begin{pmatrix} 1 & 1 \\ 1 & 0 \end{pmatrix}^{k} = \begin{pmatrix} F_{k+1} & F_k \\ F_k & F_{k-1} \end{pmatrix}, \] on \(F_k\) és el \(k\)-èsim nombre de Fibonacci. Amb exponenciació ràpida (\(A^{2k} = (A^k)^2\) i \(A^{2k+1} = A \cdot A^{2k}\)) n’hi ha prou amb uns \(\log_2 k\) productes de matrius per calcular \(F_k\), en lloc dels \(k\) passos del bucle del tema 2. Implementar l’exponenciació ràpida és opcional.

Exercici 6.10: Classe Intervalo (mòdul intervalo.py)

L’aritmètica d’intervals treballa amb intervals tancats \([a, b]\) en lloc de amb nombres: si \(x \in [a, b]\) i \(y \in [c, d]\), la suma, la resta i el producte de \(x\) i \(y\) estan garantits en intervals que es calculen només a partir dels extrems. Es fa servir en anàlisi numèrica per fitar de manera rigorosa els errors d’arrodoniment i de mesura.

Nota6.10.1 Constructor __init__(self, inf, sup):

Crea l’interval \([\text{inf}, \text{sup}]\). Precondició: \(\text{inf} \leq \text{sup}\). Desa els extrems en atributs privats (_inf, _sup).

ConsellExemple 
I = Intervalo(1, 3)
J = Intervalo(2, 2)    # intervalo degenerado: el número 2
Intervalo(3, 1)        # ValueError
Nota6.10.2 Propietats de només lectura inf i sup:

Els extrems es llegeixen amb I.inf i I.sup, però no es poden modificar (@property sense setter).

ConsellExemple 
I = Intervalo(1, 3)
print(I.inf, I.sup)    # 1 3
I.inf = 5              # AttributeError
Nota6.10.3 Propietats longitud i punto_medio:

Propietats calculades: la longitud \(b - a\) i el punt mitjà \((a + b)/2\).

ConsellExemple 
I = Intervalo(1, 3)
print(I.longitud, I.punto_medio)    # 2 2.0
Nota6.10.4 Pertinença __contains__ (operador in):

x in I crida I.__contains__(x) i ha de retornar True si \(a \leq x \leq b\).

ConsellExemple 
I = Intervalo(1, 3)
print(2 in I, 3 in I, 4 in I)    # True True False
Nota6.10.5 Representació __repr__ i __str__:

repr(I) retorna Intervalo(1, 3) i str(I) retorna [1, 3].

ConsellExemple 
I = Intervalo(1, 3)
print(repr(I))    # Intervalo(1, 3)
print(I)          # [1, 3]
Nota6.10.6 Igualtat i hash __eq__, __hash__:

Dos intervals són iguals si tenen els mateixos extrems. Com que els intervals no es modifiquen després de crear-se, han de ser hashables (vegeu l’apartat 6.4.2 del tema), de manera que es puguin desar en conjunts.

ConsellExemple 
print(Intervalo(1, 3) == Intervalo(1, 3))                  # True
print(len({Intervalo(1, 3), Intervalo(1, 3), Intervalo(0, 1)}))   # 2
Nota6.10.7 Mètode interseccion(otro):

Retorna l’interval \([a, b] \cap [c, d] = [\max(a, c), \min(b, d)]\), o None si els intervals són disjunts.

ConsellExemple 
I = Intervalo(1, 3)
print(I.interseccion(Intervalo(2, 5)))    # [2, 3]
print(I.interseccion(Intervalo(4, 6)))    # None
print(I.interseccion(Intervalo(3, 4)))    # [3, 3]
Nota6.10.8 Suma i resta __add__, __radd__, __sub__, __rsub__:

\[ [a, b] + [c, d] = [a + c,\ b + d], \qquad [a, b] - [c, d] = [a - d,\ b - c]. \] Un nombre \(x\) es tracta com l’interval degenerat \([x, x]\), de manera que també funcionen I + 1, 1 + I, I - 1 i 1 - I.

ConsellExemple 
I = Intervalo(1, 3)
J = Intervalo(2, 5)
print(I + J, I - J)      # [3, 8] [-4, 1]
print(I + 1, 10 - I)     # [2, 4] [7, 9]
Nota6.10.9 Producte __mul__, __rmul__:

\[ [a, b] \cdot [c, d] = [\min(ac, ad, bc, bd),\ \max(ac, ad, bc, bd)]. \] Com a la suma, un nombre \(x\) es tracta com \([x, x]\).

ConsellExemple 
print(Intervalo(1, 3) * Intervalo(2, 5))     # [2, 15]
print(Intervalo(-1, 2) * Intervalo(-3, 1))   # [-6, 3]
print(2 * Intervalo(1, 3))                   # [2, 6]
ImportantEl problema de la dependència

L’aritmètica d’intervals garanteix que el resultat conté tots els valors possibles, però els pot sobreestimar. Si \(X = [-1, 1]\):

X = Intervalo(-1, 1)
print(X - X)    # [-2, 2], aunque x - x = 0 para todo x
print(X * X)    # [-1, 1], aunque x² ∈ [0, 1]

L’aritmètica d’intervals tracta cada aparició de \(X\) com si fos una variable independent. Per això, en anàlisi numèrica importa com s’escriu una expressió: fórmules matemàticament equivalents poden donar intervals d’amplada diferent.

Exercici 6.11: Classe Permutacion (mòdul permutacion.py)

Una permutació de \(\{0, 1, \ldots, n-1\}\) és una bijecció \(\sigma\) d’aquest conjunt en si mateix. Es representa amb la llista de les seves imatges: Permutacion([1, 2, 0]) és la permutació \(\sigma\) amb \(\sigma(0) = 1\), \(\sigma(1) = 2\) i \(\sigma(2) = 0\). Amb la composició, les permutacions de \(n\) elements formen el grup simètric \(S_n\), d’ordre \(n!\).

Nota6.11.1 Constructor __init__(self, imagen):

Crea la permutació amb la llista d’imatges donada. Precondició: la llista conté exactament una vegada cadascun dels nombres \(0, 1, \ldots, n-1\) (és a dir, defineix una bijecció).

ConsellExemple 
sigma = Permutacion([1, 2, 0, 4, 3])
Permutacion([0, 0, 1])    # ValueError: 0 aparece dos veces
Permutacion([1, 2, 3])    # ValueError: falta el 0
Nota6.11.2 Mètode de classe identidad(n):

Retorna la permutació identitat de \(\{0, \ldots, n-1\}\).

ConsellExemple 
print(Permutacion.identidad(4))    # Permutacion([0, 1, 2, 3])
Nota6.11.3 Avaluació __call__ i mida __len__:

sigma(i) retorna la imatge de i i len(sigma) retorna \(n\).

ConsellExemple 
sigma = Permutacion([1, 2, 0, 4, 3])
print(sigma(0), sigma(3), len(sigma))    # 1 4 5
Nota6.11.4 Representació, igualtat i hash:

repr(sigma) retorna Permutacion([1, 2, 0, 4, 3]). Dues permutacions són iguals si tenen la mateixa llista d’imatges. Les permutacions han de ser hashables.

ConsellExemple 
print(Permutacion([1, 0]) == Permutacion([1, 0]))    # True
print(len({Permutacion([1, 0]), Permutacion([1, 0]), Permutacion([0, 1])}))   # 2
Nota6.11.5 Composició __mul__:

sigma * tau és la composició \(\sigma \circ \tau\): primer s’aplica \(\tau\) i després \(\sigma\), \[ (\sigma \circ \tau)(i) = \sigma(\tau(i)). \] Precondició: les dues permutacions tenen la mateixa mida.

ConsellExemple 
s = Permutacion([1, 0, 2])    # intercambia 0 y 1
t = Permutacion([0, 2, 1])    # intercambia 1 y 2
print(s * t)                  # Permutacion([1, 2, 0])
print(t * s)                  # Permutacion([2, 0, 1])  — S_3 no es conmutativo
Nota6.11.6 Mètode inversa():

Retorna la permutació inversa \(\sigma^{-1}\), que compleix \(\sigma \circ \sigma^{-1} = \sigma^{-1} \circ \sigma = \text{id}\).

ConsellExemple 
sigma = Permutacion([1, 2, 0, 4, 3])
print(sigma.inversa())                                       # Permutacion([2, 0, 1, 4, 3])
print(sigma * sigma.inversa() == Permutacion.identidad(5))   # True
Nota6.11.7 Potència __pow__:

sigma ** k és la composició de \(\sigma\) amb si mateixa \(k\) vegades, amb \(\sigma^0 = \text{id}\). Si \(k\) és negatiu, \(\sigma^{k} = (\sigma^{-1})^{-k}\).

ConsellExemple 
sigma = Permutacion([1, 2, 0, 4, 3])
print(sigma ** 2)                                   # Permutacion([2, 0, 1, 3, 4])
print(sigma ** -1 == sigma.inversa())               # True
print(sigma ** 6 == Permutacion.identidad(5))       # True
Nota6.11.8 Mètode ciclos():

Tota permutació es descompon en cicles disjunts. Per exemple, \(\sigma = [1, 2, 0, 4, 3]\) envia \(0 \to 1 \to 2 \to 0\) i \(3 \to 4 \to 3\), així que \(\sigma = (0\ 1\ 2)(3\ 4)\). El mètode retorna la llista de cicles com a tuples, sense els punts fixos (cicles de longitud 1). Cada cicle comença pel seu element més petit i els cicles apareixen ordenats pel seu primer element.

ConsellExemple 
print(Permutacion([1, 2, 0, 4, 3]).ciclos())    # [(0, 1, 2), (3, 4)]
print(Permutacion([0, 2, 1, 3]).ciclos())       # [(1, 2)]
print(Permutacion.identidad(4).ciclos())        # []
ImportantAlgorisme

Recorreu els elements \(i = 0, 1, \ldots, n-1\). Si \(i\) encara no s’ha visitat, seguiu l’òrbita \(i, \sigma(i), \sigma(\sigma(i)), \ldots\) fins a tornar a \(i\), marcant cada element com a visitat. Un conjunt (set) és l’estructura adequada per als elements visitats.

Nota6.11.9 Mètode orden():

L’ordre de \(\sigma\) és el menor \(k \geq 1\) amb \(\sigma^k = \text{id}\). És el mínim comú múltiple de les longituds dels seus cicles (podeu fer servir math.lcm).

ConsellExemple 
print(Permutacion([1, 2, 0, 4, 3]).orden())    # 6 = mcm(3, 2)
print(Permutacion.identidad(4).orden())        # 1
Nota6.11.10 Mètode signo():

Un cicle de longitud \(\ell\) s’escriu com a producte de \(\ell - 1\) transposicions. El signe de \(\sigma\) és \((-1)^t\), on \(t\) és la suma de \(\ell - 1\) sobre tots els seus cicles: val \(1\) si la permutació és parella i \(-1\) si és senar.

ConsellExemple 
print(Permutacion([1, 2, 0, 4, 3]).signo())    # -1   (2 + 1 = 3 transposiciones)
print(Permutacion([1, 2, 0]).signo())          # 1
print(Permutacion.identidad(4).signo())        # 1
ImportantComprovació amb el grup simètric

Amb itertools.permutations(range(4)) es generen les \(4! = 24\) permutacions de \(S_4\). Exactament la meitat, 12, són parelles (formen el grup alternat \(A_4\)), i els ordres que apareixen són \(1, 2, 3\) i \(4\):

from itertools import permutations

s4 = [Permutacion(list(p)) for p in permutations(range(4))]
print(len(s4))                                   # 24
print(sum(1 for p in s4 if p.signo() == 1))      # 12
print(sorted({p.orden() for p in s4}))           # [1, 2, 3, 4]

ImportantRequisits mínims per mètode

Per a cada mètode de les classes dels exercicis 6.9, 6.10 i 6.11, el fitxer de prova corresponent ha d’incloure:

  1. Almenys 2 casos normals: entrades típiques amb resultats coneguts.
  2. Almenys 1 cas límit (si escau): matriu \(1 \times 1\), interval degenerat, permutació identitat…
  3. Almenys 1 test de precondició violada (si el mètode té precondició): fent servir pytest.raises(ValueError).

A més, incloeu almenys una prova d’una propietat algebraica per classe, per exemple: \((AB)^T = B^T A^T\), \(\det(AB) = \det(A)\det(B)\), \(I \subseteq I + J - J\) per a intervals, o \((\sigma\tau)^{-1} = \tau^{-1}\sigma^{-1}\) i \(\operatorname{sgn}(\sigma\tau) = \operatorname{sgn}(\sigma)\operatorname{sgn}(\tau)\) per a permutacions.

# tests/test_matriz.py
import pytest

from t06_paquete.matriz import Matriz

# --- constructor ---

def test_constructor_filas_distinta_longitud():
    with pytest.raises(ValueError):
        Matriz([[1, 2], [3]])

def test_constructor_copia_las_filas():
    filas = [[1, 2], [3, 4]]
    a = Matriz(filas)
    filas[0][0] = 99                      # modificar la lista original...
    assert a[0, 0] == 1                   # ...no modifica la matriz

# --- producto de matrices ---

def test_producto_por_identidad():
    a = Matriz([[1, 2], [3, 4]])
    assert a @ Matriz.identidad(2) == a

def test_producto_no_conmutativo():
    a = Matriz([[1, 2], [3, 4]])
    b = Matriz([[0, 1], [1, 0]])
    assert a @ b != b @ a

def test_producto_dimensiones_incompatibles():
    with pytest.raises(ValueError):
        Matriz([[1, 2, 3]]) @ Matriz([[1, 2, 3]])

# --- determinante ---

def test_determinante_2x2():
    assert Matriz([[1, 2], [3, 4]]).determinante() == -2

def test_determinante_no_cuadrada():
    with pytest.raises(ValueError):
        Matriz([[1, 2, 3], [4, 5, 6]]).determinante()

# --- propiedad algebraica ---

def test_traspuesta_del_producto():
    a = Matriz([[1, 2], [3, 4], [5, 6]])
    b = Matriz([[1, 0, 2], [0, 1, 3]])
    assert (a @ b).traspuesta() == b.traspuesta() @ a.traspuesta()
